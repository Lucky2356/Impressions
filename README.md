# Впечатления

Локальное кроссплатформенное приложение для хранения личных предпочтений, впечатлений, рекомендаций и коллекций: продуктов, блюд, фильмов, сериалов, музыки, книг, игр, товаров, городов, мест и собственных типов данных.

**Windows и Android.** Архитектура готова к сборке под iOS.

> Рабочее название временное и меняется в одном месте — `lib/core/config/app_config.dart`.

## Главное

- **Данные — локально.** Без сервера, облака, регистрации, аналитики, рекламы и телеметрии. Записи, фотографии и ключи не покидают устройство.
- **Сеть — только по делу и по желанию.** Наружу уходят ровно две вещи, обе отключаются в настройках: штрихкод при поиске товара и запрос списка выпусков при проверке обновлений. Содержимое записей не передаётся никогда.
- **Обмен только файлом.** Данные передаются подписанным контейнером `*.impressions`, который пользователь создаёт сам.
- **Мнение отделено от объекта.** Фильм «Интерстеллар» — общий объект; оценка Александра и оценка Ларисы — разные записи. Редактирование одного мнения не меняет другое.
- **Ничего не удаляется молча.** Изменения сохраняются как неизменяемые версии, удаление заменено архивированием.

## Возможности

**Каталог и структура**
- Древовидные категории произвольной вложенности (не менее 10 уровней) с защитой от циклов, перемещением веток без потери записей и хлебными крошками `Продукты / Колбасы / Папа может`
- Одна основная категория и любое число дополнительных; теги — отдельный плоский механизм
- Каталог: три режима отображения, фильтры по типу, категории (с учётом подкатегорий), отношению, сортировка и поиск с подсказкой ввода
- Подборки — ручные списки с собственным порядком

**Записи**
- Быстрое добавление: обязательно только название
- Отношение (обожаю → избегаю), оценка 0–10 с шагом 0.5, заметки, дата впечатления
- История версий с восстановлением любой прошлой версии
- Поиск возможных дублей без автоматического объединения
- Свои поля у любого типа объектов: текст, число, дата, флажок, выбор из списка
- Фотографии: проверка сигнатуры файла, очистка EXIF (включая геолокацию), исправление ориентации, миниатюры, дедупликация по SHA-256

**Штрихкоды и товары**
- Добавление товара по штрихкоду или QR-коду: камера на Android, USB-сканер, ручной ввод и распознавание с фотографии или снимка экрана на Windows
- Собственный декодер EAN-13, EAN-8 и UPC-A: работает с повёрнутым и зеркальным снимком, без камеры и без сети
- Цепочка товарных баз с русскими названиями: Open Food Facts (русская витрина и мировая), Open Beauty Facts, Open Pet Food Facts, Open Products Facts, UPCitemdb, OpenGTINDB — источники включаются по отдельности
- Повторное сканирование того же кода ведёт к существующей карточке, а не создаёт копию
- Автодополнение карточек товаров в фоне, не чаще раза в сутки; введённое вручную название не заменяется

**Уведомления и обновления**
- Центр уведомлений: входящие изменения, итоги импорта, обновлённые товары, новая версия приложения
- Проверка выпусков на GitHub со ссылкой на установщик

**Профили**
- Собственный профиль и до 10 импортированных
- Локальные имя и заметка о человеке, которые не передаются при экспорте и не стираются при повторном импорте
- Сравнение двух профилей в шести режимах
- Перенос чужой записи себе: чужие оценка и отношение не копируются, сохраняется источник рекомендации

**Обмен и безопасность**
- Подпись Ed25519, отпечаток профиля вида `7A91-1F42-8B03`
- Экспорт: весь профиль, ветка категории, подборка; с фотографиями и без; с паролем
- Настройки приватности для каждой записи вплоть до «Только мне»
- Импорт с проверкой контрольных сумм и подписи, защитой от Zip Slip, лимитами и транзакционным применением
- Повторный импорт обновляет существующую копию профиля, не создавая дублей
- Резервная копия перед каждым импортом, проверка целостности

## Установка

**Windows** — скачайте установщик со [страницы выпусков](https://github.com/Lucky2356/Impressions/releases) и запустите его. Права администратора не нужны: приложение ставится в профиль пользователя. Удаление — как у обычной программы; данные при этом остаются.

**Android** — скачайте APK оттуда же. Потребуется разрешить установку из неизвестных источников.

## Интерфейс

Полностью русский, светлая и тёмная темы, собственная дизайн-система с локальным шрифтом Inter. На Windows — боковая навигация и горячие клавиши, на Android — нижняя навигация и нижние листы. Раскладка рассчитана на разрешения от Full HD до 4K: на широком мониторе растёт число карточек в ряду, а не их размер, а колонка текста остаётся читаемой.

Горячие клавиши: `Ctrl+N` — новая запись, `Ctrl+B` — сканировать код, `Ctrl+F` — поиск, `Ctrl+I` — импорт, `Ctrl+E` — экспорт, `Ctrl+P` — профили, `Ctrl+,` — настройки, `Escape` — закрыть диалог.

## Сборка

Требуется Flutter stable 3.44+, Android SDK для APK, Visual Studio с компонентами Desktop C++ и включённый режим разработчика Windows. Для установщика — [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`).

```powershell
./scripts/bootstrap.ps1       # зависимости и кодогенерация
./scripts/check.ps1           # формат, анализ, все тесты
./scripts/build_windows.ps1   # build/windows/x64/runner/Release/
./scripts/build_installer.ps1 # dist/Impressions-<версия>-windows-x64-setup.exe
./scripts/build_android.ps1   # build/app/outputs/flutter-apk/app-release.apk
```

## Тесты

105 тестов: юнит-тесты нормализации и хешей, декодирование штрихкодов из синтезированных изображений (включая повёрнутые и зеркальные), сравнение версий, пользовательские поля, тесты базы (дерево категорий, версии, полнотекстовый поиск, транзакции), обработка изображений, перенос записей, сравнение профилей, криптография, сквозной цикл экспорт → импорт → повторный импорт, резервные копии, тесты экранов и golden-тесты дизайна.

```powershell
./scripts/check.ps1
```

## Что уходит в сеть

Ничего не отправляется без явного действия или включённой настройки, и никогда не передаётся содержимое записей.

| Когда | Куда | Что уходит |
| --- | --- | --- |
| Сканирование или ввод штрихкода | Включённые товарные базы | Только сам штрихкод |
| Автодополнение товаров (по умолчанию выключено) | Они же | Штрихкоды карточек с незаполненными полями |
| Проверка обновлений | `api.github.com` | Ничего, кроме самого запроса |

Оба механизма выключаются в «Настройки → Товарные базы и обновления». При выключенных настройках приложение не делает ни одного сетевого запроса.

## Ограничения текущей версии

- Камера-сканер работает на Android; на Windows код вводится вручную, USB-сканером или распознаётся с изображения
- Из товарных баз распознаются коды EAN-13, EAN-8 и UPC-A; экзотические форматы (Code 128, ITF-14) с фотографии не читаются
- Обновление приложения скачивается вручную по ссылке: приложение не устанавливает его само
- Закрытый ключ защищён DPAPI на Windows и приватным каталогом приложения на Android
