# Впечатления

Локальное кроссплатформенное приложение для хранения личных предпочтений, впечатлений, рекомендаций и коллекций: продуктов, блюд, фильмов, сериалов, музыки, книг, игр, товаров, городов, мест и собственных типов данных.

**Windows и Android.** Архитектура готова к сборке под iOS.

> Рабочее название временное и меняется в одном месте — `lib/core/config/app_config.dart`.

## Главное

- **Полностью локально.** Без сервера, облака, регистрации, аналитики, рекламы, телеметрии и скрытых сетевых запросов. Приложение работает без интернета.
- **Обмен только файлом.** Данные передаются подписанным контейнером `*.impressions`, который пользователь создаёт сам.
- **Мнение отделено от объекта.** Фильм «Интерстеллар» — общий объект; оценка Александра и оценка Ларисы — разные записи. Редактирование одного мнения не меняет другое.
- **Ничего не удаляется молча.** Изменения сохраняются как неизменяемые версии, удаление заменено архивированием.

## Возможности

**Каталог и структура**
- Древовидные категории произвольной вложенности (не менее 10 уровней) с защитой от циклов, перемещением веток без потери записей и хлебными крошками `Продукты / Колбасы / Папа может`
- Одна основная категория и любое число дополнительных; теги — отдельный плоский механизм
- Каталог: три режима отображения, фильтры по типу, категории (с учётом подкатегорий), отношению, сортировка и поиск с подсказкой ввода
- Подборки — ручные списки с собственным порядком

**Записи**
- Быстрое добавление: обязательно только название
- Отношение (обожаю → избегаю), оценка 0–10 с шагом 0.5, заметки, дата впечатления
- История версий с восстановлением любой прошлой версии
- Поиск возможных дублей без автоматического объединения
- Фотографии: проверка сигнатуры файла, очистка EXIF (включая геолокацию), исправление ориентации, миниатюры, дедупликация по SHA-256

**Профили**
- Собственный профиль и до 10 импортированных
- Локальные имя и заметка о человеке, которые не передаются при экспорте и не стираются при повторном импорте
- Сравнение двух профилей в шести режимах
- Перенос чужой записи себе: чужие оценка и отношение не копируются, сохраняется источник рекомендации

**Обмен и безопасность**
- Подпись Ed25519, отпечаток профиля вида `7A91-1F42-8B03`
- Экспорт: весь профиль, ветка категории, подборка; с фотографиями и без; с паролем
- Настройки приватности для каждой записи вплоть до «Только мне»
- Импорт с проверкой контрольных сумм и подписи, защитой от Zip Slip, лимитами и транзакционным применением
- Повторный импорт обновляет существующую копию профиля, не создавая дублей
- Резервная копия перед каждым импортом, проверка целостности

## Интерфейс

Полностью русский, светлая и тёмная темы, собственная дизайн-система. На Windows — боковая навигация и горячие клавиши, на Android — нижняя навигация и нижние листы. Раскладка рассчитана на разрешения от Full HD до 4K.

Горячие клавиши: `Ctrl+N` — новая запись, `Ctrl+F` — поиск, `Ctrl+I` — импорт, `Ctrl+E` — экспорт, `Ctrl+P` — профили, `Escape` — закрыть диалог.

## Стек

Flutter · Dart · Material 3 · Riverpod · Drift/SQLite · cryptography (Ed25519, AES-GCM) · crypto · image · file_selector · image_picker · desktop_drop · archive · intl

## Сборка

Требуется Flutter stable 3.44+, Android SDK для APK, Visual Studio с компонентами Desktop C++ и включённый режим разработчика Windows.

```powershell
./scripts/bootstrap.ps1       # зависимости и кодогенерация
./scripts/check.ps1           # формат, анализ, все тесты
./scripts/build_windows.ps1   # build/windows/x64/runner/Release/
./scripts/build_android.ps1   # build/app/outputs/flutter-apk/app-release.apk
```

## Тесты

91 тест: юнит-тесты нормализации и хешей, тесты базы (дерево категорий, версии, полнотекстовый поиск, транзакции), обработка изображений, перенос записей, сравнение профилей, криптография, сквозной цикл экспорт → импорт → повторный импорт, резервные копии, тесты экранов и golden-тесты дизайна.

```powershell
./scripts/check.ps1
```

## Ограничения текущей версии

- Шрифт — системный (Segoe UI / Roboto), локальный Inter не подключён
- Закрытый ключ шифруется локальным секретом в базе, а не в хранилище ключей ОС
- Сканирование штрихкодов и раздел входящих изменений не реализованы и в интерфейсе не показываются
- Пользовательские поля типов описаны в модели данных, но редактора полей пока нет
