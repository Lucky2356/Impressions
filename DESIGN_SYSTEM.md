# Дизайн-система

Собственная визуальная система приложения (не дефолтный Material). Ориентир — макет **YowBooks** (`image/1.jpg`): светлый прохладный фон, белые карточки с мягкими границами, **оранжевый** акцент, левая боковая навигация со сгруппированными разделами, карточки статистики с мини-графиками, ряды обложек с прогресс-барами, карточки подборок. Стиль применён к домену приложения (профили, впечатления, категории), а не буквально к книгам. Все токены и компоненты — в `lib/core/theme/` и `lib/design_system/`; стили не дублируются вручную (§3.4).

## 1. Палитра (`lib/core/theme/app_colors.dart`)

Цвета заданы как `ThemeExtension AppColors` со светлым и тёмным вариантами; доступ из виджетов — `context.colors`.

**Светлая тема** (основная, по макету): фон `#F3F4F6` (прохладный светло-серый), поверхность `#FFFFFF`, мягкая поверхность `#F5F6F8`, «геройская»/персиковая `#FFF3E9`, основной текст `#191C21`, вторичный `#6C7178`, приглушённый `#9CA3AD`, граница `#EBEDF0`.

**Тёмная тема** (глубокая, не абсолютно чёрная): фон `#141517`, поверхность `#1D1F23`, текст `#ECEDEF`.

**Акцент**: оранжевый `#F5822B` (основной интерактивный), персиковая заливка активного пункта навигации `#FFF3E9`. Вторичные: синий/зелёный/красный для графиков (`chartBlue/chartGreen/chartRed`), плюс палитра из 10 индивидуальных цветов профилей; цвет выбирается детерминированно по id (`profileColorFor`).

Цветом смысл не передаётся в одиночку: рядом всегда иконка и текст (§30).

## 2. Типографика (`app_typography.dart`)

Системный стек: **Segoe UI** (Windows) → **Roboto** (Android/fallback), оба с полной кириллицей, без сетевой загрузки. Локальный Inter можно подключить позже (заготовка в `pubspec.yaml`).

Шкала (§3.3): крупный экранный заголовок (`displayLarge` 36/700), заголовок раздела (`headlineMedium` 24/600, `headlineSmall` 20/600), заголовок карточки (`titleLarge` 18/600), основной текст (`bodyLarge` 16/400), вторичный (`bodyMedium` 14), подпись (`bodySmall` 13), текст кнопок (`labelLarge` 15/600), компактные чипы (`labelMedium` 13/600), метаданные (`labelSmall` 12/500).

## 3. Отступы, радиусы, тени, анимации (`app_dimens.dart`)

- Отступы по сетке 4pt: 2/4/8/12/16/20/24/32/40/48/64.
- Радиусы: 12/16/20/24 (основной диапазон 16–24 по §3.1) + pill.
- Тени очень мягкие: одна тень `blur 18, y+6`, цвет `#14000000` (свет) / `#33000000` (тьма).
- Переходы 150/200/250 мс, кривая `easeInOutCubic`.
- Минимальная сенсорная область 48 (§30).

## 4. Темы (`app_theme.dart`)

Единая `ThemeData` на основе Material 3 с собственным `ColorScheme`, `TextTheme` и оформлением компонентов (AppBar без тени, карточки без заливки-tint, чипы-pill, скруглённые кнопки/поля/диалоги/листы). Светлая/тёмная/системная переключаются через `themeModeProvider` (Riverpod). Обе темы сохраняют одинаковую иерархию и качество.

## 5. Компоненты (`lib/design_system/`)

Базовые: `AppCard`, `CoverImage` (обложка с заглушкой при отсутствии фото), `ProfileAvatar`, `ProfileCard`, `ProfileSwitcher`, `RelationChip`, `StatusChip`, `RatingView` (0–10, шаг 0.5), `Breadcrumbs`, `EntryCard`/`EntryCardCompact`, `EmptyState`, `ConfirmDialog`, `TransferButton`.

В стиле YowBooks: `NavSidebar` (боковая навигация с группами и активным пунктом), `StatCard` (число + мини-график), `Sparkline` (плавный график через CustomPainter, без библиотек), `SectionHeader` (+ «Показать все»), `CollectionCard`/`NewCollectionCard` (подборки с тегом и прогрессом, пунктирная «новая»), `CoverProgress` (обложка с прогресс-баром).

Компоненты, зависящие от реальных данных (дерево категорий, панель фильтров, окно предпросмотра импорта, блок сравнения профилей, галерея изображений, поле быстрого добавления, карточка результата импорта), реализуются в своих функциональных этапах поверх этих токенов и атомов.

## 6. Оболочка и главная

`lib/features/shell/app_shell.dart` — адаптивная оболочка: боковая навигация + верхняя шапка (заголовок, поиск, помощь, профиль) на широком экране; нижняя навигация + FAB на узком. `lib/features/home/home_screen.dart` — главная-дашборд (карточки статистики, недавние записи, подборки, боковая панель с рекомендацией и «Хочу попробовать»). Внутренняя «Галерея компонентов» (`lib/design_system/gallery/`) сохранена для debug.

## 7. Адаптивность (§4), FHD → 4K

Брейкпоинты (`AppDimens`): компактный < 640, средний 640–960, широкий ≥ 1200 (боковая навигация вместо нижней). Внутри главной: боковая панель показывается при ширине ≥ 1080; число колонок сеток (статистика, обложки, подборки) пересчитывается через `LayoutBuilder`. Максимальная ширина контента ограничена (`~1720`), контент центрируется — на ultrawide/4K нет чрезмерно растянутых карточек. Flutter использует логические пиксели, поэтому раскладка масштабируется вместе с DPI монитора (FHD, 2K, 4K). Ширина боковой панели и максимальная ширина — в `AppDimens` (легко подстроить).

## 8. Доступность (§30)

Минимальная сенсорная область 48; смысл не только цветом (иконка+текст в чипах); поддержка длинных названий (ellipsis, перенос); заглушки для отсутствующих фото; контрастные пары текст/фон в обеих темах.
