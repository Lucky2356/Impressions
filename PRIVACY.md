# Приватность

## 1. Принципы

Приложение локальное: без сервера, облака, регистрации, Firebase, аналитики, рекламы, телеметрии и скрытых сетевых запросов. Записи, заметки, оценки, фотографии и ключи никогда не покидают устройство иначе как через явно созданный пользователем файл профиля `*.impressions`.

Единственные сетевые обращения — поиск товара по штрихкоду и проверка обновлений (раздел 4). Оба выключаются в настройках, и ни одно из них не передаёт содержимое записей.

## 2. Уровни доступности (§25)

У записи, поля, фотографии и заметки есть настройка доступности:

- Только мне;
- Можно передавать;
- Передавать без заметки;
- Передавать без фотографий;
- Передавать только основную информацию;
- Передавать в защищённом файле.

Перед экспортом показывается точный состав передаваемых данных и что именно исключено.

## 3. Локальные данные о других (§5.3)

Личные локальные заметки и локальное имя о чужом профиле **никогда** не экспортируются вместе с ним и не стираются при повторном импорте этого профиля.

## 4. Сеть

Шрифты и любые ресурсы интерфейса лежат в самом приложении и не загружаются из интернета. Приложение полноценно работает офлайн: без сети недоступен только поиск товара по коду, всё остальное — включая ручной ввод названия — работает как обычно.

Сетевых обращений ровно два, оба перечислены в «Настройки → Товарные базы и обновления».

### 4.1. Поиск товара по штрихкоду

Происходит, когда пользователь сам отсканировал или ввёл код, и только если настройка «Искать товар по штрихкоду» включена (по умолчанию включена).

- **Что уходит:** цифры штрихкода и заголовок `User-Agent` с названием и версией приложения.
- **Что не уходит:** название записи, заметки, оценка, отношение, категории, фотографии, идентификатор профиля, идентификатор устройства — ничего из этого в запросе нет.
- **Куда:** только в те базы, что включены переключателями. Список фиксирован и виден в настройках; произвольные адреса приложение не запрашивает.
- **Что сохраняется:** полученные название, бренд и категория записываются в карточку товара локально. Приложение не сообщает базам, что пользователь с этим товаром сделал.

Каждый источник — сторонний сервис со своей политикой; запрос к нему виден его владельцу вместе с IP-адресом, как у любого посещения сайта. Если это нежелательно, выключите настройку: добавление товара по коду продолжит работать, название нужно будет ввести самому.

### 4.2. Автодополнение карточек товаров

По умолчанию **выключено**. Когда включено — не чаще раза в сутки отправляет штрихкоды тех карточек, у которых пустые поля, и заполняет только пустое. Введённое человеком название не заменяется никогда.

### 4.3. Проверка обновлений

По умолчанию включена, не чаще раза в 20 часов. Запрашивает список выпусков проекта на `api.github.com`. Ничего о пользователе и его данных не передаётся; в запросе нет даже установленной версии — сравнение происходит на устройстве. Установщик не скачивается и не запускается сам: приложение только показывает ссылку.

## 5. Изображения

EXIF-геолокация удаляется при добавлении изображения (§16). Путь к исходному пользовательскому файлу не сохраняется.
