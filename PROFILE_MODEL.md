# Модель профилей

Профиль представляет конкретного человека. Профиль и устройство — разные сущности (§5).

## 1. Типы профилей

- мой основной профиль;
- мой профиль на другом устройстве;
- внешний профиль другого человека;
- архивированный внешний профиль.

Локально может храниться до 10 импортированных профилей помимо собственных.

## 2. Поля профиля (§5.1)

`id (постоянный UUID)`, имя, фамилия/доп. имя (необяз.), псевдоним, аватар, основной цвет, краткое описание, дата создания, дата последнего изменения, открытый ключ, отпечаток открытого ключа, версия профиля, режим повторной передачи данных, настройки приватности владельца.

## 3. Устройства (§5.2)

`UUID`, профиль владельца, пользовательское название, тип устройства, модель (если безопасно доступна), ОС, дата регистрации, дата последнего экспорта, дата последнего импорта, локальный статус доверия.

Технические идентификаторы в обычном интерфейсе не показываются. У записи может отображаться человекочитаемое: «Добавлено Александром с устройства Samsung S24, 23 июля 2026 года».

## 4. Настройки профиля (§5.3)

**Передаваемые** (могут уходить в экспорт): отображаемое имя, аватар, цвет, описание, разрешение повторного экспорта, настройки публичности, подпись профиля.

**Локальные** (никогда не экспортируются): локальное название человека, локальная заметка, закрепление, скрытие, собственный цвет отображения, показывать на главной, доверенный профиль, уведомлять о новых изменениях, дата последнего просмотра, локальные связи и псевдонимы.

Пример: владелец называется «Александр», локально сохранён как «Саша с работы». **Повторный импорт не стирает локальное имя и локальные настройки.**

## 5. Цифровая подпись (§22)

При создании собственного профиля генерируется пара ключей Ed25519.

- **Закрытый ключ**: только локально, не попадает в обычный экспорт, подписывает пакеты, защищается локальным шифрованием.
- **Открытый ключ**: входит в профиль и экспорт, используется для проверки последующих импортов.

Отпечаток (fingerprint) — усечённый хеш открытого ключа, показывается человеку для доверия: `7A91-1F42-8B03`.

Сценарии:
- первый импорт → «Новый профиль: Александр. Отпечаток: … Доверять?»;
- последующие → «Профиль подтверждён. Подпись файла корректна»;
- тот же UUID, но другой ключ → «Подпись профиля изменилась. Автоматический импорт остановлен» (профили не объединяются автоматически).

Для переноса собственного профиля на другое устройство создаётся отдельный зашифрованный «паспорт профиля» с закрытым ключом.

## 6. Определение профиля при импорте (§20)

Профиль определяется по совокупности: `profileId` + открытый ключ + цифровая подпись. Если профиль уже существует — обновляется существующая локальная копия, второй профиль с тем же владельцем не создаётся.
